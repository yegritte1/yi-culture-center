# 彝族文化主题跳跃小游戏 - 设计提示词

## 游戏概述
一个类似谷歌离线恐龙跳跃（Chrome Dino Game）的横版无尽跑酷游戏，融入彝族传统文化元素。

## 核心玩法
- **操作方式**：空格键/点击屏幕跳跃，躲避障碍物
- **游戏机制**：角色自动向右奔跑，玩家控制跳跃时机
- **难度递增**：速度逐渐加快，障碍物出现频率增加
- **计分系统**：根据奔跑距离计分

## 视觉风格
- **整体风格**：像素风/手绘民族风，色彩鲜明
- **背景**：彝族山寨风景，有连绵的山峦、蓝天白云
- **色调**：以彝族传统色彩为主（黑、红、黄、蓝、绿）

## 游戏元素设计

### 主角（可替换）
- 彝族服饰风格的角色
- 默认提供基础角色框架，支持自定义贴图替换
- 跳跃动画、奔跑动画、死亡动画

### 障碍物（彝族元素）
1. **山峦** - 高低起伏的山峰，需要跳跃越过
2. **索玛花（杜鹃花）** - 地面低矮障碍物，可蹲下躲避或跳跃
3. **彝族图腾柱** - 中等高度障碍物
4. **奔跑的老虎** - 移动障碍物，增加挑战性

### 背景元素
- 远处的彝族山寨建筑
- 飘动的云朵
- 索玛花丛（装饰性）
- 彝族纹样装饰边框

## 技术规格
- **平台**：Web浏览器（HTML5 Canvas）
- **分辨率**：自适应，推荐 800x400 基础尺寸
- **帧率**：60fps
- **控制**：键盘（空格/方向键）+ 触摸屏支持
